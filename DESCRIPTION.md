Gnostic Code - IntelliJ IDE Plugin providing language support for GG Game Engine.

## Features

### Syntax Highlighting
- **Valkyrie**: Script, shader, schema syntax highlighting
- **VON**: Data format syntax highlighting
- **Voc**: Widget language syntax highlighting
- **Galgame**: Galgame script syntax highlighting

### Semantic Highlighting
- VON pair key highlighting
- VON dict type highlighting

### Code Folding
- VON dict and list code folding
- Display element count and type name when folded

### Structure View
- File structure tree
- VON dict, pair, list nodes support

### Other Features
- Symbol search and reference
- File creation support

## Supported File Types

### Valkyrie Language
- `.script` - Game script
- `.shader` - Shader
- `.schema` - Schema definition

### VON Data Format
- `.von` - Object file
- `.meta` - Metadata
- `.config` - Config file
- `.scene` - Scene file
- `.prefab` - Prefab
- `.material` - Material file
- `.mesh` - Mesh file
- `.skeleton` - Skeleton file
- `.animation` - Animation file
- `.animator` - Animator file
- `.locale` - Localization file
- `.gnostic` - Generic file

### Voc Language
- `.widget` - Editor UI component

### Galgame Language
- `.galgame` - Galgame script

### Other Resource Files
- `.asset` - Asset file
- `.mixer` - Mixer
- `.brush` - Brush
- `.bundle` - Bundle
- `.terrain` - Terrain
- `.navigation` - Navigation
- `.story` - Story
