## ✨ Features

### 🎨 Syntax Highlighting
- Valkyrie script, shader, schema
- VON data format
- Voc Widget language
- Galgame script

### 🔦 Semantic Highlighting
- VON pair key highlighting
- VON dict type highlighting

### 📁 Code Folding
- VON dict and list folding
- Display element count and type name

### 🌳 Structure View
- File structure tree
- VON dict, pair, list nodes

### 🔍 Find Usages
- Symbol search and reference

### 📄 File Creation
- Create VON, Valkyrie, Widget files

## 📥 Installation

1. Open IntelliJ IDEA
2. Go to `Settings` → `Plugins` → `Marketplace`
3. Search for `Gnostic Code`
4. Click `Install`
